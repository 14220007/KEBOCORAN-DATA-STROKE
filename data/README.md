# Data

Dataset tidak disertakan dalam repositori ini.

1. Unduh *Stroke Prediction Dataset* (fedesoriano, 2021) dari Kaggle:
   https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset
2. Simpan file `healthcare-dataset-stroke-data.csv` di folder ini.

Opsional, untuk bagian skrining literatur: letakkan file ekspor Scopus (`export_*.csv`) di folder ini.
